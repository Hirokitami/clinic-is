# ИС медицинской клиники

Программная реализация командного проекта (ПР 6, СРО 12, СРО 15).
Python 3 + Flask (веб-формы в окне браузера), база данных SQLite (файл `clinic.db`).

## Запуск на Mac

```bash
cd clinic_is
python3 -m venv venv
source venv/bin/activate
pip install flask
python3 init_db.py        # создать базу и тестовые записи (повторный запуск пересоздаёт базу)
python3 app.py            # открыть в браузере http://127.0.0.1:5000
```

Остановить программу: `Ctrl + C`.
При следующем запуске выполните только `source venv/bin/activate` и `python3 app.py`.

## Версии по этапам

Переменная `CLINIC_STAGE` показывает программу в состоянии нужного этапа:

```bash
CLINIC_STAGE=1 python3 app.py   # ПР 6: вход и форма «Запись на приём»
CLINIC_STAGE=2 python3 app.py   # СРО 12: + регистрация пациента, список и отмена записей
python3 app.py                  # итоговая версия 1.0 (СРО 15)
```

## Автоматическая проверка

```bash
python3 tests.py     # 23 проверки, рабочая база не изменяется
```

## Состав

- `schema.sql` – структура БД (справочники ref_* из СРО 10 и таблицы основных объектов);
- `init_db.py` – создание базы, справочники и тестовые записи (расписание на 14 дней вперёд от текущей даты);
- `app.py` – программа: формы, проверки, работа с БД;
- `templates/`, `static/` – оконные формы (HTML-шаблоны) и оформление;
- `tests.py` – проверочные ситуации.
